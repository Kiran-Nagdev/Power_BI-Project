# Power_BI-Project
ShopNest Store Data Analysis Project
 Project Overview
* ShopNest Store is an end-to-end Retail / E-Commerce Data Analysis Project focused on understanding sales performance, customer behavior, product trends, and operational efficiency.

* This project uses business data to generate meaningful insights through data cleaning, transformation, SQL/Python analysis, and dashboard reporting. It helps management make data-driven decisions to improve revenue, customer satisfaction, and profitability.

### Tasks Performed
### Data Cleaning
* Removed null values
* Fixed data types
* Handled duplicates
* Standardized columns
### Sales Analysis
* Total revenue calculation
* Monthly sales trend
* Category-wise revenue
* Average order value
### Customer Analysis
* Repeat vs new customers
* Top customers by spend
* Region-wise customer distribution
### Product Analysis
* Best-selling products
* Low-performing categories
* Quantity sold trends
### Operational Analysis
* Delayed deliveries
* Cancellation rate
* Order completion ratio
### Payment Analysis
* Preferred payment methods
* Installment usage trends
### Customer Satisfaction
* Average review score
* Low-rated products/orders

### Skills Demonstrated
* Data Cleaning & Preparation
* SQL Query Writing
* Python Data Analysis
* Dashboard Development
* Business KPI Reporting
* Trend Analysis
* Customer Analytics
